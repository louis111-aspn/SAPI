비용계획 Bottom-Up 프로세스 플로우
4단계 단방향 흐름 · STATUS 필드로 단계 전환 제어 · 제출 이후 수정 불가 원칙 적용

SAPI Step 3 개별 담당자
3개별 담당자 비용계획 입력 및 제출 (SAPI Excel Add-in)
Excel Add-in에서 전년도 비용 실적 자동 조회(READ-ONLY) → 당기 비용계획 입력(WRITE)
사이드 패널에서 계정별 가이드라인 참조 / HARD 제약 위반 시 입력 즉시 차단 (빨간 셀 + 에러 표시)
AI 에이전트: 전년 실적 기반 계절성 패턴 보존 + 성장률 적용 계획 초안 자동 생성
상태 전환: 임시저장(DRAFT) → 제출(SUBMITTED) · 제출 이후 수정 불가(LOCK)

합계 조회 기준 선택: 승인 기준 / 제출 기준 / 전체 기준(임시저장 포함)
승인(APPROVED) → 마감(CLOSED) 전환 · 마감 후 SAC Planning으로 데이터 이관
APPROVAL_HIST 테이블에 모든 상태 전환 이력 보존 (Audit Trail)

데이터베이스 모델 (ERD)
9개 핵심 테이블 · COST_PLAN을 중심으로 버전/조직/계정/가이드라인/승인이력 연계
COST_PLAN 테이블이 버전·조직·계정·담당자를 모두 참조하는 사실 테이블(Fact Table)로, 모든 비용계획 데이터의 단일 진실 공급원(SSOT) 역할을 수행함
핵심 테이블 설계 원칙
COST_PLAN
월별(period) × 계정(acct_cd) × 담당자 단위 입력. STATUS: DRAFT→SUBMITTED→APPROVED→CLOSED. 제출 이후 서버에서 수정 차단.
COST_GUIDELINE
constraint_type으로 HARD/SOFT 구분. 버전별 독립 설정 가능. SAPI 입력 시 실시간 검증 호출.
COST_ACTUAL
READ-ONLY 참조 전용. SAC에서 주기적으로 동기화. SAPI에서 전년 비교 기준값으로 활용.
APPROVAL_HIST
모든 상태 전환 이력(생성·수정·제출·승인·반려·마감) 보존. 규정 준수 감사 대응용.
